Our Services

Vtechiee supports business-critical systems from planning and implementation through migration, security, monitoring and day-to-day operations. Each service is delivered according to the customer's environment, access requirements and business priorities.

SAP Business One Services

SAP Business One implementation, upgrades, patching, migrations and administration for SAP HANA and Microsoft SQL Server environments. Services include SLD, License Manager, Service Layer, Browser Access, mobile services, add-ons, backups, troubleshooting and performance support.

SAP HANA & SQL Database

Database installation support, connectivity, backup and restore, tenant and company database administration, storage checks, log management, performance investigation and database migration support for SAP HANA and Microsoft SQL Server.

Cloud Infrastructure

Microsoft Azure and AWS architecture, virtual machines, storage, private networking, security groups, VPN connectivity, backup, monitoring and migration support. Environments are designed for secure access, manageable operations and business continuity.

Windows & Linux Administration

Deployment, configuration, hardening and troubleshooting for Windows Server, Remote Desktop Services, SUSE Linux Enterprise Server for SAP Applications and Ubuntu. Support includes services, certificates, storage, patching and operational documentation.

Identity & Secure Remote Access

Microsoft Entra ID SSO, MFA and Conditional Access planning, secure RDP and RDS access, AWS Client VPN, Azure VPN, SoftEther VPN and site-to-site connectivity. Access is designed around authorised users, least privilege and protected business systems.

Network & Firewall Solutions

FortiGate firewall support, routing, VLAN, SD-WAN, IPSec tunnels, SSL VPN, firewall policies, secure publishing and network troubleshooting. We also support centralised firewall logging and operational visibility across multiple locations.

Monitoring, Backup & Automation

Grafana, Loki, rsyslog, Azure Monitor and Log Analytics dashboards, backup health checks, alerting and operational reports. PowerShell and Linux automation are used to standardise recurring administration and reduce manual effort.

Web Applications & Business Portals
